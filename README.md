## 🚀 Selected Projects

### Cyber-Physical Federated Learning Security Framework

A research-oriented framework for evaluating federated learning under sensor spoofing, compromised clients, and Byzantine aggregation attacks. Experiments examine detection performance, prediction errors, data heterogeneity, ablations, and execution latency.

### NIS2 Internal Asset & CVE Compliance Auditor

A Python-based security assessment tool that uses Nmap and the NIST National Vulnerability Database to support internal asset discovery, vulnerability analysis, CVSS-based assessment, and compliance reporting.

### Reliability-Aware AoI Scheduling in Energy-Harvesting IoT Systems

A study of lightweight reinforcement learning for Age of Information scheduling under energy-harvesting disruptions and duty-cycle constraints, with an emphasis on reliability-related metrics and performance variability.

### MacroMate

An on-device contextual-bandit meal recommendation application exploring personalized recommendations and adaptive decision-making.
